# Code of conduct

Alephgrid adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/)
as its code of conduct, in full. It applies in the repository, its issues, pull requests and
discussions, and anywhere someone represents the project.

In short: be welcoming and respectful, assume good intent, give and accept feedback on the
work rather than the person, and do not harass anyone.

## Reporting

If you see or experience behaviour that breaks this code, contact the maintainers privately at
**conduct@REPLACE-BEFORE-LAUNCH** (to be set before the repository is public). Reports are
read by the maintainers only and kept confidential. The maintainers will respond and act as
described in the Covenant's enforcement guidelines.
